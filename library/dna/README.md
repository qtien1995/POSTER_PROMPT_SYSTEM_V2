# Reference DNA Library

Use for approved transferable design principles extracted from references.

Recommended file format:
`DNA_<NNN>_<DESCRIPTIVE_NAME>.md`

Record:
- source/reference;
- INSPIRATION or RECREATION intent;
- layout/grid;
- hierarchy;
- palette;
- typography;
- composition/camera;
- lighting;
- material/texture;
- metaphor mechanism;
- information architecture;
- emotional positioning;
- do-not-copy surface traits;
- approved reusable rules.
