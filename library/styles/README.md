# Curated Style Library

Store only user-approved reusable style DNA here.
Do not treat every one-off poster or reference as a permanent style.

Recommended file format:
`STYLE_<NNN>_<NAME>.md`

Each style card should contain:
- use cases;
- core visual grammar;
- hierarchy;
- palette logic;
- typography logic;
- composition rules;
- metaphor patterns;
- anti-patterns;
- reference sources;
- tested failure notes.
