# V2 Short Workflow

## Default create mode
Keep the visible workflow short.

### 1. INPUT
Accept natural input: idea, rough notes, content, product, story, reference image, or existing poster.
Do not force the user to fill a rigid brief.

### 2. INTERNAL MESSAGE + COPY LOCK
Before writing the master prompt, internally resolve only what matters:
- audience/context;
- one core message;
- factual claims that are safe to use;
- exact poster copy;
- unresolved facts that must not be invented.

Do not expose a long strategy worksheet unless the user asks for it.

### 3. ONE BEST DESIGN DIRECTION
Choose the strongest visual direction based on message effectiveness, not merely what looks fashionable.
Resolve:
- big idea;
- hero visual / metaphor;
- subject + action + relationships;
- composition;
- style / visual DNA;
- text layout.

Default: choose one direction yourself. No 3-PA output unless explicitly requested.

### 4. ONE FINAL MASTER PROMPT
Compile the entire solution into one production-ready master prompt using `templates/final_master_prompt.md`.
The prompt must contain both visual instructions and exact on-image copy.

## Multi-image exception
If the user explicitly requests 2+ separate images/carousel frames, each frame is a distinct asset and therefore receives one complete standalone master prompt. Keep shared visual DNA consistent across the sequence.

## Essential-information rule
Do not ask questions for things you can safely infer as design choices.
Ask only when missing information would materially change factual accuracy, identity, required exact copy, or user intent.
