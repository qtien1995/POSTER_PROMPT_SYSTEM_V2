# POSTER STUDIO & MASTER PROMPT SYSTEM V3.0 — Antigravity Workspace

Hệ thống studio sản xuất poster thương mại và kỹ nghệ Master Prompt đa nền tảng tối tân:
1. **Direct High-End Poster Synthesis:** Trực tiếp tạo ảnh đồ họa thương mại hoàn thiện với chữ tiếng Việt sắc nét bằng công cụ AI tích hợp (`generate_image`) khi người dùng yêu cầu.
2. **Production 4-Frame Prompt Suite:** Tạo bộ prompt thực chiến đồng bộ cho 4 khung hình (Carousel 4 Frames) theo kịch bản và phong cách đã chốt cho Midjourney v6/v7, FLUX.1 Pro, ChatGPT Images 2.5, Google Flow / Imagen 3.
3. **99% Visual DNA Cloning Engine:** Bóc tách sâu 6 tầng Visual DNA (Bố cục, Ánh sáng, Màu sắc, Chất liệu Shaders, Quang học máy ảnh, Kiến trúc Typography đồ họa tích hợp) đạt chuẩn OpenAI ChatGPT Images 2.5.
4. **Art-Centric Philosophy (Anti-AI Slop):** Loại bỏ hoàn toàn hình ảnh người mẫu nhựa CGI giả tạo (*plastic skin*); tôn vinh chất liệu thủ công thật (Cắt giấy 3D đa tầng, Mộc bản, Gốm Kintsugi men rạn, Thêu cung đình, Tranh kính Tiffany).

## 3 Chế Độ Vận Hành

- **`PROMPT_ONLY` (Mặc định):** Sau khi chốt nội dung, style hoặc chọn phương án (PA), hệ thống sẽ viết **Bộ Prompt Thực Chiến tương ứng cho 4 ảnh (Carousel 4 Frames)** để bạn tự test trên Midjourney, FLUX, ChatGPT Images 2.5, Google Flow. Tuyệt đối không tự ý tạo ảnh bằng AI.
- **`DIRECT_IMAGE` / Sinh Ảnh AI:** CHỈ KHI NÀO bạn yêu cầu tạo ảnh (như: *"tạo ảnh"*, *"vẽ ảnh"*, *"render ảnh"*, *"hãy tạo 4 ảnh này"*), hệ thống mới kích hoạt công cụ `generate_image` để tạo ảnh trực tiếp.
- **`HYBRID`:** Chỉ kích hoạt khi bạn yêu cầu rõ ràng xuất cả ảnh render và prompt cùng lúc.
